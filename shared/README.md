# shared/

PlatformIO library folder shared by TALON and VECTOR via `lib_extra_dirs`.

`LanzonesOS/` — the shared OS layer: OLED layout engine (breadcrumb + hint
bar), 5-button non-blocking input with hold/fast-scroll gestures, menu &
editor framework, buzzer patterns, status LEDs, battery monitor, flash
profile storage, watchdog. Added in Step 2.
